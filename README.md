#  Portfolio Optimization

## Overview

This project applies Modern Portfolio Theory (MPT) to analyze risk and return across multiple assets and identify efficient portfolio allocations.

## Key Concepts

- Diversification
- Risk vs Return
- Correlation
- Covariance
- Modern Portfolio Theory
- Portfolio Management

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- yfinance

## Learning Outcome

Learned how portfolio construction and diversification can improve risk-adjusted returns by balancing expected returns against volatility.
